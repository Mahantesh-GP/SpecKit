# PowerPoint navigation

The accompanying `SpecKit_SDD_Process_Flows.pptx` contains two slides, one for each workflow. Each stage is a PowerPoint shape and the three bottom buttons link to relative Markdown paths.

**Before sharing the PPT broadly:** Commit the Markdown files to Git, copy the actual Git web URLs for each README, process flow, and developer guide, and replace the relative hyperlinks in PowerPoint. Relative file hyperlinks may not work after the PPT is moved or viewed in Teams/browser. No Git URL was invented.
