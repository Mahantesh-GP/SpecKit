/speckit.specify

Create a reference external API integration activity that demonstrates how a consuming team can integrate an external service through WorkflowActivities.

The activity should:
- accept the standard workflow activity input contract,
- delegate the external operation through a separate service abstraction,
- return the standard workflow activity result,
- keep external-service-specific logic outside the activity,
- support a placeholder/stub implementation so the activity can be tested without access to a real external API.

This is a reusable reference pattern only. Do not implement any specific business workflow or real external system integration.
